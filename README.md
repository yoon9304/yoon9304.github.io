# Engineer Portfolio (GitHub Pages)

## 구성
- `index.html`: 한국어/영어 전환이 가능한 반응형 포트폴리오 단일 페이지

## GitHub Pages로 공개하기
1. GitHub 계정에 로그인하고 새 Public repository를 만듭니다.
2. 저장소 이름은 `YOUR-GITHUB-USERNAME.github.io` 로 지정합니다.
3. 이 폴더의 `index.html`을 저장소 최상위(root)에 업로드합니다.
4. 저장소의 Settings → Pages에서 배포 상태를 확인합니다. (Deploy from a branch / main / root)
5. 잠시 후 `https://YOUR-GITHUB-USERNAME.github.io` 에서 접속할 수 있습니다.

※ 실제 주소는 GitHub 사용자명이 정해져야 확정됩니다. 이 프로젝트 파일 자체가 도메인을 등록하거나 사이트를 인터넷에 게시하지는 않습니다.

## 수정할 부분
- `[현재 회사명]`, `[이전 회사명]`, `20XX.XX` 등 경력 정보
- 프로젝트의 `[상황]`, `[조치]`, `[결과]`
- `your.email@example.com`, `Your Name`
- 상단 소개 문구 및 역량 목록

개인정보와 고객사 기밀은 공개 전에 반드시 삭제하거나 익명화하세요.
